## Non-negotiables
- Zero request-time network calls. No TAGO client, no `DATA_GO_KR_SERVICE_KEY` read in MVP.
- Seed rows per core ADR-C05: `departures` `HH:MM`, `tz: "Asia/Seoul"`, `durationMin`, train grade + number, adult fare KRW, `source` (public Korail timetable/fare page URL + date read). No times known → row not seeded.
- `kind: "timetable"`; `price` = seeded adult fare, currency KRW.
- Works with empty `.env` — never `NOT_CONFIGURED`.

## Notes

- Seed: `train-seed.json` 683 rows (one per train per directional pair; 580 daily, 103 with `days`), 8 stations in `train-stations.json` (coords: en.wikipedia station pages via API, 2026-10-02). Grades: KTX 311, KTX-Sancheon 180, ITX-Saemaeul 84, Mugunghwa 47, KTX-Eum 28, ITX-Maeum 24, KTX-Cheongryong 9.
- Generated by `pnpm korea:snapshot` (`scripts/snapshot-korea-trains.mts`); pages cached `.cache/korea-trains/<date>/` (gitignored). Script throws on unknown grade / unparsed row; skips rows without fare (0 this run).
- **Source is NOT Korail.** korail.com/ticket/search is bot-protected: in Chrome, the search POSTs to an obfuscated `/web_s/…` path → HTTP 500, "no trains" shown (observed 2026-10-02). Not bypassed. Used train.asamaru.net per-pair pages instead (public, no login; 7 days embedded, grade/number/times/duration/fares; looks TAGO-derived). Every row `source` = that page URL (decoded, readable); read date = top-level `checked` 2026-10-02, `sampleWeek` 2026-10-02..08 (Fri..Thu; Oct 3 = holiday on a Sat).
- **Fare caveat:** `fareKrw` = source's 일반실 어른. It is ~9% under the commonly quoted Korail fares (Seoul–Busan KTX 54,400 vs 59,800 on travel guides; Daejeon 21,600 vs 23,700). Gangneung KTX-Eum 27,600 matches. Source shows 특실 = 일반실, i.e. likely TAGO base fare. Not "corrected" by hand — verify on korail.com in a real browser before quoting prices to judges.
- Matching: nearest station ≤ 15 km picks a **city**; all stations of that city match (Seoul + Yongsan), like china-rail. So Seoul→Gwangju returns Seoul + Yongsan departures; Mokpo→"Seoul" lands at Yongsan. `covers` false outside seeded pairs (Taiwan/Malaysia no longer get `NOT_CONFIGURED`).
- `days` = departure weekday (origin date = `q.date`); arrive = depart + `durationMin`, rolls past midnight.
- Offers: `kind:"timetable"`, `price {amount: fareKrw, currency:"KRW", asOf: checked}`, carrier = romanised grade, `bookingUrl` = `https://www.korail.com/ticket/search/general` (no OD params).
- B02 hook: `schema.ts` (train schemas; add bus ones), `seed.ts` (`parseTrainSeed`/`trainSeed`; add `busSeed`), `index.ts` `createKoreaTagoProvider({ train })` — add `bus` search + mode to dispatch. `modes` is `["train"]` until then. `registry.test.ts` `LANDED` += `korea-tago`.
