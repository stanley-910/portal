## Non-negotiables
- No request-time network calls. Seed is committed JSON.
- Every seed train cites `source` (thsrc.com.tw timetable page or PDF, with date checked).
- Times per ADR-C05: `"HH:MM"` local, `tz: "Asia/Taipei"`, emitted as ISO `+08:00`. No price (`kind: "timetable"`).
- Trains that do not run daily carry `days` (0 = Sun … 6 = Sat); omit = daily. Only emit offers for trains running on `q.date`'s weekday.
- `ProviderFailure` codes only from the contract; unseeded OD → `covers` false, not an error.

## Notes

- Seed: `tdx/seed.json`, 181 trains (S 89, N 92; 125 daily, 56 with `days`), 12 stations. Generated by `pnpm thsr:snapshot [monday]` (`scripts/snapshot-thsr.mts`); raw responses cached in `.cache/thsr/` (gitignored).
- Times source: thsrc.com.tw timetable search (`POST /TimeTable/Search`, see doc `taiwan-tdx.md` § Gotchas), Taipei ↔ Zuoying, 14 calls for sample week **2026-10-12 (Mon) – 2026-10-18 (Sun)**, checked 2026-10-02. Every train `source` = THSR timetable page. `days` = weekdays the train ran in that week (Oct 10 holiday week avoided). Stop times identical across the week for every train no (script asserts).
- Stations: TDX guest `/v2/Rail/THSR/Station` (1 call) — ids, codes, zh names, lat/lng. TDX guest timetable endpoints 401 → not used; no request-time TDX.
- Scope: only trains serving **both Taipei and Zuoying**. Short runs (e.g. Taipei–Taichung only, Nangang–Tainan) missing → intermediate pairs under-count. Re-snapshot with more OD pairs if needed.
- Site gives one time per stop (departure); destination time = its departure at intermediate stops (~1–2 min late vs arrival). Terminal = arrival.
- Matching: nearest station ≤ 20 km per end; same station both ends → `covers` false. `covers` is date-free; a pair with no train that weekday → `[]`, not an error.
- Cross-midnight: smaller HH:MM rolls a day; `days` keyed on train start day, origin past midnight checks previous weekday.
- Seed validated by zod (`schema.ts`) at module load; seed test fails first.
- Link-out: `https://irs.thsrc.com.tw/IMINT/?locale=en` — linked as "Online Booking" on en.thsrc.com.tw; loads in Chrome (booking form, all 12 stations), curl gets empty reply/timeout. No OD params. 12Go not used (S01 todo).
