# Decisions

These files record what we decided and why, so nobody (person or agent) has to re-argue it. If you want to reverse a decision, edit its entry: set the status to `superseded` and link to the decision that replaces it. Don't delete it.

| File | Covers |
|---|---|
| [foundation.md](foundation.md) | The stack, the design system pipeline, and the custom globe |
| [globe.md](globe.md) | Globe interaction: zoom, pan, and how the plane looks |
| [multiplayer.md](multiplayer.md) | Live layer, trip model, identity, storage, AI agent, payments |

**Status values:**
- `decided`: agreed, but not built yet.
- `built`: in the code.
- `on hold`: we're waiting on something.
- `superseded`: replaced by another decision, which the entry links to.

**Open questions** are listed at the end of each file. If a Linear ticket disagrees with a decision here, this log wins, and the ticket needs updating.
