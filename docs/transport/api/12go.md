# 12Go Asia — API ground truth
Checked: 2026-10-02 · Modes: ferries, buses, trains (also vans, taxis, flights) · Seat: shared — ferries Cata, buses Ahmet

## Verdict
- **No public API. No public docs.** API is partner-only: "subject to prior consent of 12GO" + "additional confidential conditions". Requires "established website"; you email them. [S1][S2]
- **Not usable in hackathon timeline.** No self-serve key, no published endpoints, approval time unknown. Do not plan on live 12Go search/prices.
- Parent co. Travelier sells "Travelier Connect" single API (bus/ferry/train) — B2B, "Let's Talk" sales form only, no docs/pricing. Same gate. [S6]
- **Free + usable now: affiliate deep links** (50% of 12Go revenue, ~$3/booking, 30-day cookie) — direct (agent.12go.asia) or via **Travelpayouts** program (reuse our TP account). [S1][S4][S5]
- Biggest blocker: no data. We get **zero** schedules/prices from 12Go legally → our app must own route/station data (static seed) and hand off to 12Go route page for live price + booking.
- Do NOT use scrapers (Apify/parse.bot "12go API") or 12Go internal `/api/nuxt/*` endpoints: agreement bans copying/modifying 12Go products; robots.txt disallows them; site bot-challenges (observed HTTP 202, empty body). [S2][S7]

## Auth + base URL
- API: **unknown** — not public. `unverified`.
- Deep links: no auth. Public route page pattern `https://12go.asia/{lang}/travel/{from-slug}/{to-slug}` e.g. `https://12go.asia/en/travel/bangkok/koh-samui` (indexed by search engines; TP example uses `/ms/travel/bangkok/phuket`). [S4][S11]

## Endpoints we use
No API endpoints available. Link-building only:

| Method + path | Purpose | Key params | Key response fields |
|---|---|---|---|
| GET (browser nav) `https://12go.asia/en/travel/{from}/{to}` | Route page: live options, prices, booking | `{from}`,`{to}` slugs; date param `unverified`; affiliate param (commonly cited `?z=<id>`) `unverified` | HTML page, not data |
| GET (browser nav) `https://c44.travelpayouts.com/click?shmarker={marker}&promo_id=1764&source_type=customlink&type=click&custom_url={urlencoded 12go url}` | TP-tracked 12Go link | `shmarker`=TP marker, `custom_url` | 302 to 12go.asia (`unverified` behaviour) |
| POST `https://api.travelpayouts.com/links/v1/create` | Generate TP partner link server-side | header `X-Access-Token`; body `trs`,`marker`,`shorten`,`links[{url,sub_id}]` | `result.links[].partner_url`, `code` |

Example (TP links API, from TP docs shape [S10]; 12Go URL as input `unverified` until we try):
```bash
curl -s -X POST https://api.travelpayouts.com/links/v1/create \
 -H "X-Access-Token: $TRAVELPAYOUTS_TOKEN" -H "Content-Type: application/json" \
```

## Errors
- No API → no documented errors. `unverified`.
- Observed: `curl` of route page → HTTP 202, 0 bytes (bot challenge). Server-side fetch of 12Go pages won't work; links must open in user's browser.
- TP links API: per-link `code` (`success` or failure), top-level `status` [S10].

## Gotchas
- Don't promise "live ferry prices" in UI. Show our static info + "Check times & prices on 12Go →".
- Two affiliate paths — pick ONE per link (direct `agent.12go` ID vs TP marker); don't double-tag.
- TP program may need Project review; a fresh hackathon site with no traffic may be declined (sites from 1,000 MAU for some programs) [S9]. Apply day 1; fallback = plain un-tracked 12Go link (works, just no commission).
- Slugs: guessing wrong slug → 12Go page 404/redirect `unverified`. Hand-verify each seed route in browser.
- Non-English lang prefixes `he,hi,km,lo,my` disallowed in robots.txt — use `/en/` [S7].
- Third-party "12go APIs" (Apify, parse.bot) are scrapers → ToS risk, flaky, paid. Rejected.
- Bookings completed on an operator site = no commission [S2].
- If we ever email for API: say Next.js app, describe flow; terms are confidential → don't commit their docs to repo.
