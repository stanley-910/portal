# Logos

The Portal logo: a hand-drawn globe split by a tilted horizon, with the word "Portal" in Instrument Sans SemiBold, already outlined.

- `portal-logo-horizontal-light.svg` / `-dark.svg`: headers and navigation. Ink `#283020` on day paper; cream `#e7dcc2` on night paper.
- `portal-logo-stacked-light.svg` / `-dark.svg`: splash, landing and about screens.
- `portal-mark-light.svg` / `-dark.svg`: the globe alone.
- `portal-mark.svg`: the globe alone, switching between day and night inks with the viewer's colour scheme. Use it as the favicon.

Use the files as they are: never redraw, recolour or re-letter them.
