# Tag

A small printed label naming the airport at a point on the globe.

- Provide the three-letter airport code as children. Nothing else goes in a tag.
- Place it beside the thing it names: centred about 30px below a star pin, or about 24px right of and 22px below the plane.
- Show at most one tag per pin, and one on the plane while flying.
