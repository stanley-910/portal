# PlaceHeader

Where the two registers meet: an interface eyebrow over a place name set in the atlas serif, with an italic detail line.

- Provide `name` (the place, e.g. `Paris`), and optionally `eyebrow` (interface text, e.g. `Flights to`) and `detail` (e.g. `Charles de Gaulle · CDG`).
- Use it whenever a screen, panel or card is about a place. The name is the page's heading: set `as` to the right level (default `h2`).
- Keep the eyebrow short and functional. Never put interface words (buttons, labels) in the serif, and never set the place name in the sans.
